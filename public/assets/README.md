# Recursos de proyectos

`into-the-dark-title.webp` es una versión optimizada de `assets/ui/main_menu/title.png` del repositorio [Crisuxz/Into-the-Dark](https://github.com/Crisuxz/Into-the-Dark), revisión `73dc8a05a44c3c97746d255aa2e3989c22e8d428`.

Es el logotipo del juego, no una captura de gameplay. Se utiliza para presentar el proyecto colaborativo DevCrew; no se atribuye la creación individual del recurso a Cristian. Los derechos del material original permanecen con sus respectivos autores.

Los demás diagramas del portfolio son composiciones conceptuales hechas con HTML, CSS e iconos Lucide, identificadas como tales en la interfaz.
